# Recipe Website Landing Page

## Project Overview
This is a beginner-friendly Recipe Website Landing Page built using HTML and CSS.

## Technologies Used
- HTML5
- CSS3

## Concepts Practiced
- Navigation Bar
- Flexbox
- Background Images
- Linear Gradient
- Hover Effects
- CSS Transitions
- Buttons
- Logo Design

## What I Learned
- How to create a navigation menu using ul, li, and a tags.
- How to arrange items using Flexbox.
- How to add and style background images.
- How to use hover effects and transitions.
- How to create a simple landing page layout.

## Future Improvements
- Make the website responsive.
- Add more recipe sections.
- Add dropdown menus.
- Improve mobile design.

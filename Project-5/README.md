# Login Form Project

## Project Overview

This project is a simple and clean Login Form user interface created using HTML and CSS.
It is designed to be centered on the screen and styled with modern UI elements such as icons, hover effects, and smooth input focus styles.

---

## Technologies Used

* HTML5
* CSS3
* Google Fonts (Poppins)
* Font Awesome Icons

---

## Project Structure

Project-5
│── index.html
│── app.css

---

## HTML Concepts Used

* Form element
* Input fields (text and password)
* Placeholder attribute
* Required validation
* Div layout structure
* Anchor links
* Icon integration inside inputs

---

## CSS Concepts Used

* Flexbox for center alignment
* Position absolute for icons
* Border radius for rounded design
* Box shadow for focus effect
* Hover effects for button
* Padding and margin spacing
* Transitions for smooth animation
* Responsive container width

---

## Features

* Centered login form layout
* User and password icons inside inputs
* Styled login button with hover effect
* Clean and modern UI design
* Simple and readable code structure

---

## How to Run the Project

1. Download or clone the repository
2. Open the project folder
3. Double click `index.html`

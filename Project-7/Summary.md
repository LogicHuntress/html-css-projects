# Project 1 - EduJoy Landing Page

## Project Overview

This project is a beginner-friendly landing page created using HTML and CSS. The webpage contains a navigation bar, search box, content section, and login form. The main goal of this project was to understand how different HTML and CSS concepts work together to create a complete webpage layout.

## Technologies Used

* HTML5
* CSS3

## Concepts Practiced

### HTML Concepts

* HTML Structure
* Div Containers
* Lists (ul, li)
* Links (a tag)
* Forms
* Input Fields
* Buttons

### CSS Concepts

* Background Images
* Linear Gradients
* Float
* Flexbox
* Relative Positioning
* Absolute Positioning
* Hover Effects
* Border Radius
* Layout Design

## What I Learned

* How to structure a webpage using multiple div containers.
* How to create a navigation menu using lists and links.
* How to design forms and input fields.
* How to add background images and gradient overlays.
* How to arrange elements using float and flexbox.
* How relative and absolute positioning work together.
* How to create interactive effects using hover.
* How to style buttons and form elements.
* How different sections of a webpage are connected to create a complete layout.

## Project Summary

This project helped me understand the fundamentals of web development. I learned how to build a complete landing page by combining HTML structure and CSS styling. The project introduced me to important concepts such as forms, positioning, float, flexbox, hover effects, gradients, and layout design. These concepts form the foundation for creating modern websites such as portfolios, landing pages, and business websites.
